COMO A PARTIDA É DEFINIDA

Estrutura de sets

REGRAS DA AREIA
01

Melhor de 3 sets

A equipe que vencer dois sets primeiro ganha a partida. O formato de 5 sets também pode ser escolhido antes do início.

02

Sets antes do decisivo: 21 pontos

Os sets antes do set decisivo vão até 21 pontos. É preciso abrir dois pontos de vantagem para fechar o set.

03

Set decisivo: 15 pontos

Se houver empate em sets, o último set é disputado até 15 pontos, também com diferença mínima de dois.

04

Sem limite de pontos

Se o placar empatar no ponto de fechamento, a partida continua até uma equipe alcançar a vantagem necessária.

✳

O placar destaca automaticamente a equipe vencedora e registra o resultado de cada set ao fim da partida.
